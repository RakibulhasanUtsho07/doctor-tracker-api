# Privacy and Data Governance
Collect and expose only data needed for doctor/patient tracking. Confirm exact patient fields and condition taxonomy before finalizing the schema. Restrict access to authenticated administrators; return only fields required by each UI view.
Never use real patient data in tests, screenshots, public issues or routine logs. Avoid patient details in URLs, analytics events and error reports. Redact logs. Document deletion semantics, retention and backup access. Encrypt backups where supported and restrict their access.
This engineering baseline is not a claim of legal compliance or certification. Review applicable Bangladesh law, hosting terms, organizational policy and contracts before processing real patient data.
